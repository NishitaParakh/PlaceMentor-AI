# 🎓 PlaceMentor AI

## AI-Powered Placement Readiness & Career Intelligence Platform

PlaceMentor AI is an AI-powered placement readiness and career intelligence platform designed to help students understand their current placement preparation, identify skill gaps, improve their profiles, and make informed career decisions.

The platform combines Machine Learning, Natural Language Processing, database systems, external APIs, and a web-based interface to provide personalized, explainable, and actionable placement guidance.

---

## 📌 Problem Statement

Students often find it difficult to understand their actual placement readiness and what they should improve before applying for jobs. They may have questions such as whether they are ready for placements, what their placement probability is, which technical skills they are missing, which companies they are eligible for, whether their resume is ATS-friendly, how their coding and project experience affects their profile, and what they should learn next.

Most existing placement preparation platforms provide generic resources and do not provide a complete, personalized analysis of a student's profile.

PlaceMentor AI aims to solve this problem by analyzing multiple aspects of a student's profile and providing personalized, explainable, and actionable placement guidance.

---

## 💡 Proposed Solution

PlaceMentor AI provides a centralized platform where students can evaluate their placement readiness and continuously improve their career profile.

The platform can analyze academic performance, technical skills, projects, internships, resumes, coding performance, GitHub activity, soft skills, mock interview performance, company requirements, and recruiter feedback.

Based on this information, the system provides personalized insights such as Placement Readiness Score, Placement Probability, Skill Gap Analysis, Personalized Learning Roadmap, Career Recommendations, Company Eligibility, Resume Analysis, Mock Interview Feedback, Application Tracking, Placement Trends, and Job Market Insights.

---

# ✨ Features

## 1. AI Placement Readiness Score

AI Placement Readiness Score evaluates a student's overall preparation for placements by considering factors such as academic performance, technical skills, projects, internships, coding performance, resume quality, soft skills, and interview performance. The system generates an overall readiness score that helps students understand their current placement preparation level and identify areas that need improvement.

## 2. Placement Probability Prediction with Explainable AI

Placement Probability Prediction uses Machine Learning to estimate a student's probability of getting placed based on their academic, technical, and professional profile. Explainable AI (XAI) helps the student understand which factors have the most influence on the prediction instead of showing only the final probability.

## 3. Skill Gap Analysis

Skill Gap Analysis compares a student's existing skills with the skills required for a particular job role or company. It identifies missing or weak skills and helps students understand exactly which technical areas they need to improve for their target career.

## 4. Personalized Learning Roadmap

Personalized Learning Roadmap creates a customized preparation plan based on the student's skill gaps and career goals. It recommends the topics, skills, projects, coding practice, and interview preparation that the student should focus on step by step.

## 5. AI Career Mentor / Chatbot

AI Career Mentor is an intelligent chatbot that helps students with career-related questions. It can provide guidance about career paths, required skills, companies, interviews, resumes, learning resources, and placement preparation based on the student's profile.

## 6. AI Mock Interview

AI Mock Interview allows students to practice placement interviews using an AI-based system. The system analyzes the student's responses and provides detailed feedback about answer quality, technical knowledge, communication, confidence, and areas that need improvement.

## 7. ATS-Based Resume Analyzer

ATS-Based Resume Analyzer evaluates a student's resume using Applicant Tracking System (ATS) related criteria. It checks relevant keywords, skills, formatting, job-role requirements, and missing information and provides suggestions to make the resume more suitable for targeted job applications.

## 8. GitHub & Coding Platform Integration

GitHub and Coding Platform Integration allows students to connect their coding and development profiles with PlaceMentor AI. The system can analyze repositories, projects, contributions, coding activity, and problem-solving activity to provide a better understanding of the student's practical technical skills.

## 9. Coding Performance and Project Evaluation

Coding Performance and Project Evaluation analyzes a student's coding activity and projects to understand their practical technical abilities. It can consider problem-solving activity, coding consistency, project relevance, technologies used, and project contributions while evaluating the student's technical profile.

## 10. Company Eligibility Checker

Company Eligibility Checker compares a student's profile with the eligibility requirements of a particular company. It checks factors such as academic performance, skills, projects, experience, and other requirements and identifies whether the student is eligible and what requirements may still be missing.

## 11. Company-Specific Placement Preparation

Company-Specific Placement Preparation provides personalized preparation guidance for a selected company. It uses company requirements and the student's current profile to recommend relevant technical skills, coding preparation, interview topics, resume improvements, and other preparation activities.

## 12. Recruiter Feedback Analysis using NLP

Recruiter Feedback Analysis uses Natural Language Processing (NLP) to analyze feedback provided by recruiters. The system identifies positive and negative feedback, important skills, common weaknesses, improvement areas, and summarizes the feedback so that students can understand how to improve.

## 13. Soft Skills Assessment

Soft Skills Assessment evaluates important non-technical abilities that can affect placement performance. The system can analyze aspects such as communication, interview responses, confidence, and professional interaction and provide feedback to help students improve their overall interview performance.

## 14. Student Dashboard

Student Dashboard provides students with a centralized view of their placement preparation. It can display the Placement Readiness Score, Placement Probability, skill gaps, learning roadmap, applications, resume analysis, coding performance, company eligibility, interview feedback, and career recommendations.

## 15. Recruiter Dashboard

Recruiter Dashboard provides recruiters with relevant information about student candidates. It can display skills, academic information, projects, coding performance, resume information, eligibility, assessment results, and recruiter feedback to support the candidate evaluation process.

## 16. Placement Trends Dashboard

Placement Trends Dashboard provides visual insights into placement-related trends and statistics. It can display information such as company requirements, in-demand skills, job roles, student performance trends, and job market trends using charts and other visualizations.

## 17. Application Tracker

Application Tracker helps students manage and monitor their placement applications in one place. Students can track companies they applied to, application status, interviews, selection, rejection, and other important application details.

## 18. Career Recommendation System

Career Recommendation System recommends suitable career paths and job roles based on a student's skills, academic performance, projects, coding performance, interests, and skill gaps. It helps students identify career options that match their current profile and future goals.

## 19. Real-Time Recruiter Feedback Loop

Real-Time Recruiter Feedback Loop continuously incorporates recruiter feedback into the student's profile. The analyzed feedback can be used to update skill-gap analysis, recommendations, preparation plans, and other career insights so that students can continuously improve their placement readiness.

## 20. Real-Time Job Market Integration

Real-Time Job Market Integration connects PlaceMentor AI with external job-related APIs and services to obtain current job market information. The system can use this information to identify relevant job opportunities, required skills, job roles, companies, and market trends.

## 21. Fair and Bias-Free AI Predictions

Fair and Bias-Free AI Predictions focus on making Machine Learning-based placement predictions responsible and fair. The system should use relevant academic, technical, and professional factors while avoiding inappropriate use of sensitive or unrelated personal attributes in prediction and recommendation processes.

## 22. Domain-Specific AI Models

Domain-Specific AI Models allow PlaceMentor AI to provide different analysis and recommendations for different career domains. Since Software Development, AI/ML, Data Science, Data Analytics, and other domains require different skills, the system can use domain-specific requirements for more relevant predictions and recommendations.

## 23. Cross-University & Multi-Discipline Dataset

Cross-University and Multi-Discipline Dataset allows the system to work with student data from different universities and academic disciplines. A diverse dataset can help Machine Learning models learn from different academic backgrounds and improve the generalization of placement predictions and recommendations.

## 24. Privacy & Security

Privacy and Security ensure that student information is handled safely throughout the platform. Personal information, academic details, resumes, coding profiles, applications, and interview data should be protected using appropriate authentication, authorization, secure communication, input validation, and secure data storage practices.

## 25. Cloud Deployment

Cloud Deployment allows PlaceMentor AI to be hosted online so that students and recruiters can access the platform remotely. Cloud infrastructure can support the deployment of the frontend, backend, database, Machine Learning models, NLP services, and external API integrations.

## 26. Proof-of-Work Verification using GitHub and Coding Platforms

Proof-of-Work Verification validates a student's claimed technical skills using actual evidence from GitHub repositories, coding platforms, projects, and contributions. This helps the system evaluate practical skills using real work instead of depending only on self-reported information.

## 27. Counterfactual Recommendation Engine

Counterfactual Recommendation Engine provides specific actions that could potentially improve a student's placement probability or readiness score. Instead of only showing the current prediction, the system can suggest changes such as improving DSA performance, completing a relevant project, gaining experience, or improving required skills.

Backend

🗄️ Database

SQLite is currently used as the development database for PlaceMentor AI.

The database directory contains:

database/
├── schema.sql
├── seed.sql
└── db.py

schema.sql contains the database structure and table definitions.

seed.sql contains sample development data used for testing.

db.py provides the SQLite database connection used by the backend.

The database is designed to store information related to students, skills, projects, coding profiles, resumes, companies, company requirements, applications, and other placement-related information.

The database can be expanded as additional project features are integrated.

  "skills": [
    "Python",

  "projects": 3,

An example response can be:

{
  "readiness_score": 78,
  "placement_probability": 82
}

The exact data format may be updated as the different modules are integrated.

🔌 Module Communication

The different modules communicate through structured data formats such as JSON.

The backend acts as the central layer that receives requests from the frontend, retrieves information from the database, communicates with Machine Learning and NLP modules, calls external APIs when required, and sends processed results back to the frontend.

This architecture allows each team member to develop their module independently while keeping the final system modular and easier to integrate.
